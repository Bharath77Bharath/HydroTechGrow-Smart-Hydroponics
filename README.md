# 🚀 Project Overview

HydroTechGrow is an intelligent hydroponics farming system developed to improve sustainable agriculture using IoT sensors, automation, cloud monitoring, and image processing technologies.

The project focuses on:

- 🌡️ Real-time environmental monitoring
- 💧 Automated water circulation
- 🧪 pH & TDS monitoring
- 📸 Plant disease detection using image processing
- ☁️ Cloud-based monitoring dashboard
- 🌱 Efficient vertical farming techniques

The aim is to reduce water wastage, improve crop productivity, and automate hydroponic farming using modern smart agriculture technologies.
